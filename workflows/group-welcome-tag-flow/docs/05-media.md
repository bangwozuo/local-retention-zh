## 最终交付物

### 入群欢迎与打标方案

**字段映射**

| 业务字段 | 系统字段 | 方向 | 说明 |
|---|---|---|---|
| 新客 external_userid | external_contact.external_userid | 读 | 入群事件触发读取 |
| 入群时间 | join_scene | 读 | 客户入群时间戳 |
| 欢迎语内容 | text.content | 写 | 自动回复文本 |
| 偏好标签 | follow_user.tags.tag_id | 写 | 根据互动行为打标 |
| 群 ID | chat_id | 读 | 客户加入的群标识 |

**操作清单**

1. 配置「客户群」回调事件，监听 join_scene 事件。
2. 客户入群后，自动读取 external_userid 与 chat_id。
3. 调用「发送欢迎语」接口，推送预设文本+入群须知链接。
4. 引导客户点击菜单填写偏好（口味/频次/品类）。
5. 根据填写结果，调用「编辑客户标签」接口打上对应标签。
6. 标签同步至 CRM，用于后续分层运营。
