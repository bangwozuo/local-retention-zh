# 到店核销引导

把「在途券列表」加工成核销提醒排期表：哪张券提醒、哪天提醒、话术口径、核销怎么归因。

**到期扫描与排期由 `scripts/run_flow.py` 计算，模型只做话术撰写与频控把关。**

## 能力描述

按「距到期 ≤ 3 天才提醒」的窗口规则编排：数据校验（券码是归因锚，缺失挂起）→ 到期扫描（当天截止 / D-1 / D-3 三档 + 过期损失统计）→ 提醒排期（一券只提醒一次、同一客户同一天 ≤ 1 条、同日多券只保留面额最大一张）→ 券码归因台账（核销数据 T+1 以收银系统为准）→ 三口径话术（当天截止直给 / D-1 报面额指引 / D-3 轻预告）与人工确认。假紧迫零容忍。

|---|---------|------|

## 步骤链路（DAG）

```mermaid
flowchart LR
    IN["在途券列表<br/>(wecom-customer-sync/券系统)"] --> S1["S1 数据校验"]
    S1 -->|缺券码/日期坏→中止| IN
    S1 --> S2["S2 到期扫描<br/>D-3/D-1/当天"]
    S2 --> S3["S3 提醒排期<br/>一券一提醒"]
    S3 -->|同日多券→留最紧急| S3
    S3 --> S4["S4 归因台账<br/>券码挂账"]
    S4 --> S5["S5 话术撰写<br/>+人工确认"]
    S5 --> OUT["核销提醒执行清单.xlsx"]
```

## 步骤明细

| # | 步骤 | 执行者 | 输入 | 输出 | 失败处理 |
|---|------|---------|------|------|---------|
| 1 | 数据校验 | 脚本 | 在途券列表 + 快照日 | 合格数据集 | 缺字段/日期坏退出码 2 并指出券码 |
| 2 | 到期扫描 | 脚本 | 合格数据集 | 距到期天数分桶 | 重复券码去重标注 |
| 3 | 提醒排期 | 脚本 | 分桶结果 | 提醒/不发判定 | 一券一提醒；同日多券留最紧急 |
| 4 | 归因台账 | 脚本 | 排期结果 | 券码挂账清单 | 核销对不上券码计「异常核销」人工核查 |
| 5 | 话术与确认 | 模型+人工 | 执行清单 | 定稿话术 | 假紧迫零容忍；砍单按砍后执行 |

## 使用步骤

### 方式一：带脚本（推荐，端到端）

```bash
python3 <WF_DIR>/scripts/run_flow.py --input input.json --outdir out
python3 <WF_DIR>/scripts/run_flow.py --demo
```

### 方式二：纯对话编排

把 `prompt.txt` 全文粘贴为系统提示词 → 提供在途券列表 → 按 DAG 逐步执行，末步产出排期表。

## 边界（不做的事）

- ❌ 不做假紧迫——到期日造假（D-3 说成最后一天）零容忍
- ❌ 不重复轰炸——一券只提醒一次；距到期 > 3 天的窗口外券不提醒
- ❌ 不无券码归因——没有券码的核销统计不入台账
- ❌ 不碰过期券——补发须走新券审批，不擅自承诺
- ❌ 数据缺失不编造——到期日/券码缺失的券挂起待补
