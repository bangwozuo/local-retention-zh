# 使用示例

以下示例的输入均为真实可跑数据，输出由 `scripts/run_flow.py` 实跑或按 DAG 规则生成。

---

## 示例 1：健康群清库存（零售，实跑，详见 examples/output.md）

**输入**（`examples/input.json`）：生鲜便利店 2 群（发言率均 17%），目标清库存。

**输出**（实跑，退出码 0）：双群健康 → 直接排「零售 × 清库存」模板：周一盘点定价
（毛利 ≥ 0）、周三晚 8 点 30 份秒杀（2 小时售罄率 ≥ 80%）、秒杀连带赠正价小样
（连带率 ≥ 30%）。产物含 SOP Word 报告与群健康度 PNG。

---

## 示例 2：混群况（沉默群先治理）

**输入**：

```json
{
  "shop": "老王麻辣烫",
  "industry": "餐饮",
  "week_goal": "会员日预热",
  "groups": [
    {"name": "街坊群", "members": 260, "weekly_speakers": 42, "daily_msgs": 68, "ad_ratio": 0.2},
    {"name": "外卖客群", "members": 455, "weekly_speakers": 9, "daily_msgs": 12, "ad_ratio": 0.6}
  ]
}
```

**输出**（实跑 demo 同源数据）：街坊群**健康**照常排会员日预热（D-3 投票 / D-2 晒后厨 /
D-1 定向 / 当天开启 / 次日战报 5 个动作）；外卖客群**劣化群**（发言率 2% + 广告 60%）
→ 营销类动作全部标注「劣化群先停硬广，营销类动作暂缓」，本周只做「3 题问卷 + 答题发
5 元券」重启，人数 455 > 400 同时提示拆群分层。

## 示例 3：新业态无匹配模板（通选降级）

**输入**：宠物店（industry「其他」），目标「拉新」。

**输出**：模板库无「其他 × 拉新」精确匹配 → 落到通选模板（晒单/接龙/抽奖），报告显式
标注「无精确匹配，使用行业通选模板」，并提示：通选动作的钩子需按「限时限量 / 群专属 /
空位变现」三逻辑人工定制，不冒充行业定制。

---

## 示例 4：兼职人力砍动作（频控与人力检查）

**输入**：餐饮店会员日预热，但 staff =「老板娘一人兼职」。

**输出**：5 个动作中「D-2 晒后厨实拍」（需专人拍摄）与「次日战报」合并简化，
保留 D-3 投票、D-1 定向、当天开启 3 个核心动作；预热点位由 5 压到 3，
同一客户 7 天触达 ≤ 2 次不破。**人力不足时砍动作，不砍验收标准。**
