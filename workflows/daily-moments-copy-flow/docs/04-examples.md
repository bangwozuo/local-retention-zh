# 使用示例

以下示例的输入均为真实可跑数据，输出由 `scripts/run_flow.py` 实跑或按 DAG 规则生成。

---

## 示例 1：混合素材日（实跑，详见 examples/output.md）

**输入**（`examples/input.json`）：5 条素材——2 条正常、1 条含「全网第一」、1 条缺细节、1 条营销超配。

**输出**（实跑，退出码 0）：4 条成稿（全部 ≤ 140 字）、1 条极限词拦截（含改写方向）、
1 条缺细节挂起（生成索要清单）、1 条顺延。展示全部分支：通过/拦截/挂起/顺延。

---

## 示例 2：全缺细节日（索要清单分支）

**输入**：

```json
{
  "shop": "老王麻辣烫",
  "materials": [
    {"topic": "新品肥牛", "type": "产品", "facts": []},
    {"topic": "下雨天", "type": "互动", "facts": []}
  ]
}
```

**输出**（实跑）：0 条成稿，2 条全部挂起，索要清单逐条给出——肥牛：几点到的？
进了多少斤？试吃客人原话？；下雨天：今天雨多大？店里中午坐了几桌？
**宁可当天不发，不编一天细节**。

---

## 示例 3：今日已发超配（频控拦截分支）

**输入**：`today_sent: {total: 5, marketing: 3}`，再给 3 条新素材。

**输出**（按配比规则）：今日总量与营销均已满额 → 全部素材判「顺延明日」，
排期表备注「今天已发 5 条（营销 3 条），建议明日早档发」。硬加就是刷屏，
删除率会替你算账。

---

## 示例 4：诱导分享拦截

**输入**：促销素材 facts 含「转发朋友圈并截图，凭截图减 5 元」。

**输出**：命中诱导分享词表 → 🔴 拦截，改写方向「进群直接领 / 到店报暗号减 5」——
分享可以是「额外奖励入口」，但绝不做领取门槛（微信外部内容规范红线）。
