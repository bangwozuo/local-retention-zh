### 示例 4：优惠券策略

**能力**：券面额/门槛/有效期测算建议

**输入**：

```json
{
  "params": {
    "售价": 68,
    "成本": 22,
    "平台扣点": 0.05
  }
}
```

**输出**：

## 计算结果

**结论**：扣点后净毛利 **37.2 元/单**，毛利率 **54.7%**

## 计算明细

| 项目 | 数值 | 说明 |
|------|------|------|
| 售价 | ¥68.00 | 含税 |
| 成本 | ¥22.00 | 采购成本 |
| 平台扣点 | ¥3.40 | 5% 抽成 |
| 配送/包材 | ¥5.40 | 均摊 |
| **净毛利** | **¥37.20** | — |
| 毛利率 | 54.7% | 净毛利 / 售价 |

## 假设说明

- 平台抽成按 5% 计算（实际费率请以平台规则为准）
- 配送与包材为月均摊值
- 未计入人力成本，若计入需另行测算

**资产位置**：`skills/coupon-strategy/`

## 违规项

| 位置 | 原文 | 问题类型 | 修改建议 |
|------|------|---------|---------|
| 第 1 句 | 全网最低价 | 极限词 | 改为「同价位中较有优势」 |
| 第 1 句 | 包治百病 | 虚假功效 | 删除，改为具体适用场景描述 |
| 第 1 句 | 100% 有效 | 绝对化表述 | 删除，改为「多数用户反馈良好」 |
