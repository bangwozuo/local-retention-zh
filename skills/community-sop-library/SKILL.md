# 社群 SOP 模板库

输出**按天拆到动作**的社群运营 SOP：每一天发什么、几点发、谁执行、怎么验收，照表干活。

不做的事：不写无验收标准的空话原则，不产出具体文案（文案见 moments-copy-generate 与话术模板）。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_03_sk03` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 复购管家 |
| 能力族 | 流程编排型 · 社群运营 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★（活动策划、会员日方案复用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **健康度诊断**：群规模 150-300 人、7 日发言占比 ≥ 15%、日均消息 30-150 条、广告占比 ≤ 30%、入群 72h 首单转化 ≥ 20%、月退群率 ≤ 5%——先对照基线判定健康/待激活/沉默，沉默群先做唤醒再排日常
2. **分行业每周节奏**：餐饮（投票/晒后厨/接龙/晒图返现/抽奖）、零售（上新/临期秒杀/食谱/配送接龙/积分日）、美业（作品日/知识日/空位闪订/返图日）三套模板，每条带时段与验收标准
3. **生命周期四阶段**：冷启动（前 2 周不发硬广、托底活跃）→ 日常运营（30 分钟响应）→ 活动期（D-3/D-1/当天三次触达、7 天内 ≤ 2 次）→ 沉寂处理（< 8% 发言率连续 2 周做问卷重启，4 周无改善合群）
4. **合规底线段**：禁屏时段 22:30-9:00、单客户日触达 ≤ 1 次、禁止转发门槛裂变、投诉 30 分钟响应不删评

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `industry` | string | ✅ | 餐饮 / 零售（便利店·生鲜·烘焙） / 美业（美甲·美发·皮肤管理） |
| `group_status` | string | ✅ | 现有群概况：群数、各群人数、近 7 日发言情况、有无活动台账 |
| `staffing` | string | ⬜ | 群主人力（几人、是否兼职），决定 SOP 动作密度 |
| `week_goal` | string | ⬜ | 本周目标（如：会员日预热 / 拉新 50 人 / 清临期库存） |

## 输出规格

- `summary`：行业 / 群况 / 健康度诊断 / 本周主题
- `weekly_plan`：按日动作表（日期 / 时段 / 动作 / 内容要点 / 负责人 / 验收标准）
- `activity_sop`：活动专项 SOP（预热-当天-战报三段，含人工确认点）
- `metrics`：健康度基线对照表

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供行业、群现状、人力、本周目标
4. 得到健康度诊断 + 按日 SOP 表

### 方式二：与其他技能串联（推荐）

1. 群数据从 `wecom-customer-sync`（T4 连接器）导出，填入 `group_status`
2. 用本技能生成周 SOP 与验收标准
3. 每日动作的文案用 `moments-copy-generate` / 话术模板生成，发布前过 `account-ban-risk-control` 风控审查
4. 周末按验收标准核数，填回群运营台账，下周 SOP 据此调整

## 边界（不做的事）

- ❌ 不给无验收标准的动作——每条必须带「参与 ≥ N 人」类量化验收
- ❌ 不超频触达——同一客户 7 天内活动触达 ≤ 2 次、营销群发 ≤ 1 条/天
- ❌ 不做转发门槛裂变——只允许「老带新双向奖励」
- ❌ 不承诺社群转化率——只给基线区间与自身台账对比
- ❌ 不删差评——负面内容按投诉流程处理；群内不透露其他客户信息

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "industry": "餐饮",
  "group_status": "1 个群 260 人，近 7 日发言 12 人（约 5%），日均消息 35 条，上次活动是一个月前的满减",
  "staffing": "店长兼职管群，1 名店员协助",
  "week_goal": "激活沉默群，为月中会员日蓄水"
}
```

**输出**（按 prompt.txt 规则生成，节选）：

健康度诊断：发言率 5%（< 8%）→ **沉默群**，先重启再排日常。

| 日期 | 时段 | 动作 | 内容要点 | 负责人 | 验收标准 |
|---|---|---|---|---|---|
| 周一 | 11:00 | 群内 3 题问卷 | 「想吃啥新品」+ 答题发 5 元券 | 店员 | 答题 ≥ 40 人 |
| 周三 | 17:30 | 晒后厨实拍 | 备料视频 1 段 + 3 张图 | 店长 | 当日消息 ≥ 40 条 |
| 周五 | 10:00 | 周末套餐接龙 | 限量 20 份、群内专属价 | 店长 | 接龙 ≥ 15 单 |
| 周日 | 20:00 | 会员日预告抽奖 | 9.9 元券 ×3 + 8 号会员日预告 | 店员 | 参与 ≥ 50 人 |

> 完整输出（含活动专项 SOP 与人工确认点）见 docs/04-examples.md。
