## 二、SOP 生成一致性验证

本技能为纯提示词资产（无脚本），验证方法：用 `examples/input.json` 输入跑三遍 prompt，核对生成结果一致性，并由人工对照基线表复核。

| 项 | 结果 |
|---|---|
| 3 次运行判定 | 均判「沉默群」（发言率 5% < 8% 沉默线），判定稳定 |
| 动作验收标准覆盖 | 按日动作表 7 条动作 7/7 带量化验收（答题 ≥ 40 人等） |
| 频控自检 | 会员日预热触达点位（D-3/D-1/当天）合计每客户 3 次触达 → 已按规则砍为 1v1 定向仅高价值层 + 7 天内 ≤ 2 次核对点，合规 ✅ |
| 诱导分享检查 | 全部动作无「转发才能领」类门槛，裂变仅用老带新双向奖励 ✅ |
| 空话检查 | 无「多互动、增粘性」类无验收原则 ✅ |

### 基线口径核对（与 prompt.txt 一致）

| 基线 | 数值 | 用途 |
|---|---|---|
| 群规模 | 150-300 人 | 超过 400 拆群 |
| 7 日发言率 | ≥ 15%（8% 为沉默线） | 判定健康/待激活/沉默 |
| 广告占比 | ≤ 30% | 劣化群判定 |
| 入群 72h 首单 | ≥ 20% | 欢迎语与钩子验收 |
| 月退群率 | ≤ 5% | 劣化预警 |
| 响应时限 | 客户消息 30 分钟内 | 日常运营 SOP |

## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 行业模板非穷尽 | 覆盖餐饮/零售/美业三套主干；其他业态（宠物店、健身房）需在「其他到店业态」下按钩子逻辑（限时限量/群专属/空位变现）推导 |

| 频控数值时效 | 微信平台规则持续更新，触达频控以官方最新公告为准 |
