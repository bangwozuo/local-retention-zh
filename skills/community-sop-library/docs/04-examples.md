# 使用示例

以下示例的输入均为真实运营场景数据，输出按 `prompt.txt` 内嵌规则与基线生成。

---

## 示例 1：沉默群重启（餐饮，脚本见 examples/output.md）

**输入**（`examples/input.json`）：1 群 260 人，7 日发言率 5%，店长兼职管群。

**输出要点**：判定**沉默群** → 先做「3 题问卷 + 答题发 5 元券」重启，再用晒后厨/接龙/抽奖重建节奏，一周验收：答题 ≥ 40 人、接龙 ≥ 15 单、周日抽奖参与 ≥ 50 人。同时产出会员日预热专项 SOP（D-3/D-1/当天/战报，含店主确认价格的成本确认点）。

---

## 示例 2：新群冷启动（美业）

**输入**：

```json
{
  "industry": "美业",
  "group_status": "计划建群，当前 0 群；到店客户约 300 人/月，已有 120 人微信",
  "staffing": "店主本人 + 1 名技师",
  "week_goal": "两周内建起 80-120 人的种子群"
}
```

**输出要点**：

| 阶段 | 动作 | 验收标准 |
|---|---|---|
| 建 Week1 | 到店结账时面对面扫码入群（送下次护理 10 元抵扣），每天 ≤ 15 人/号 | 首周 ≥ 60 人 |
| 建 Week2 | 老带新双向奖励：老客邀 1 位新客，双方各得 15 元券（**不设转发门槛**） | 群 ≥ 100 人 |
| 前 3 天 | 只发欢迎语 + 群规 + 首单钩子，**不发硬广** | 退群率 < 3% |
| 前 2 周 | 技术师作品日（周二 5-8 张）+ 知识日（周三 1 个护理误区）撑发言 | 发言率 ≥ 15% |

## 示例 3：健康群的周排期（零售·生鲜便利店）

**输入**：

```json
{
  "industry": "零售",
  "group_status": "2 个群各 180/210 人，7 日发言率 18%，日均消息 60 条，有月度台账",
  "staffing": "1 名专职店员管群",
  "week_goal": "清掉 60 份临期酸奶库存"
}
```

**输出要点**：判定**健康群** → 直接按零售周节奏排期。临期专项：周三晚 8 点群内秒杀（30 份，半价），D-1 预告 1 条 + 当天提醒 1 条，同一客户 7 天内触达合计 2 次不超频；验收：2 小时内售罄率 ≥ 80%，秒杀客单连带购物 ≥ 1 件正价商品（保毛利）。

## 示例 4：劣化群处置（对照生命周期 SOP）

**输入**：餐饮群 320 人，广告占比 55%（同行刷屏 + 店主自己也天天发硬广），月退群率 12%。

**输出要点**：判定**劣化群**，三步走：① 立即停硬广 1 周（广告占比目标压回 30% 以下）；② 发群规 + 开启禁屏时段（22:30-9:00）；③ 两周后发言率仍 < 8% → 按人数拆群（320 人 > 300 上限）分层：近 30 天到店的留主群，其余转 1v1 沉默运营。
