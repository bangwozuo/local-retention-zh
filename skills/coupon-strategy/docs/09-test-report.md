## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 毛利口径 | 脚本按「食材/进货成本毛利」测算，不含房租人力分摊；若按全成本毛利，安全线更窄 |
| 核销率非恒定 | 大额券核销率通常高于小额券，脚本用单一核销率近似，放量前用测试券校准 |
| 不含唤醒率预测 | 脚本算「券划不划算」，发多少张唤醒多少人不在此脚本范围（见 dormant-customer-wake-flow） |
