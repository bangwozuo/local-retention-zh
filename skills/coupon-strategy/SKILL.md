# 优惠券策略

把「发什么券」变成可验算的数字题：每张券算清**让利成本、增量毛利、ROI**，亏本的券一张不发。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_03_sk04` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 复购管家 |
| 能力族 | 测算判断型 · 营销成本核算 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | ★★★★（唤醒师、活动策划复用） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **安全面额测算**：单均毛利 = 客单价 × 毛利率 − 渠道费；安全面额上限 = 单均毛利 × 30%，超线即核销一单亏一单
2. **券成本测算**：券成本 = 面额 × 核销率（用本店历史券码数据，经验区间 20%-44%，无数据按 28% 起测并标注假设）
3. **三档策略券**：引流券（安全线×40%，14 天）/ 复购券（×70%，10 天）/ 召回券（顶格，7 天）
4. **ROI 判定**：ROI ≥ 1.5 执行；1.0-1.5 测试投放；< 1 否决。附核销率 20%/实测/44% 三情景敏感性
5. **归因口径**：到店核销必须用券码归因，给出核销数据回收字段清单

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shop` | string | ✅ | 门店名（用于产物标识） |
| `客单价` | number | ✅ | 近 30 天真实客单价（元） |
| `毛利率` | number | ✅ | 0-1 小数，如 0.60 |
| `渠道费率` | number | ⬜ | 私域发券填 0；外卖渠道约 0.18-0.23 |
| `核销率` | number | ⬜ | 本店历史券码核销率（0-1）；缺省按 0.28 并标注假设 |
| `月发放量` | number | ⬜ | 计划月发放张数，用于预算测算 |

## 输出规格

- `summary`：安全面额上限 / 门槛建议 / 核销率假设 / ROI 达标线
- `plans`：三档方案（面额 / 门槛 / 有效期 / 券后毛利率 / 预计核销人次 / 总券成本 / ROI / 风险判定）
- `sensitivity`：核销率 20% / 实测 / 44% 三情景 ROI

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供门店客单价、毛利率、渠道费率、历史核销率
4. 得到三档券方案与 ROI 判定（模型只做策略解读，金额验算建议再跑脚本核对）

### 方式二：带脚本（精确测算 + 产出文件）

```bash
python3 <SKILL_DIR>/scripts/coupon_calc.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/coupon_calc.py --demo        # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/券方案测算.xlsx` | 三档方案 / 敏感性分析 / 汇总（超安全线自动标红） |
| `out/券ROI对比.png` | 三档方案 ROI 柱状对照图 |
| `out/coupon_plan.json` | 机器可读结果，供工作流读取 |

**分工**：脚本做**数值测算**（安全线、成本、ROI、敏感性）；模型做**策略选型与话术匹配**（脚本做不了的）。数值以脚本输出为准，不要自己算。

## 边界（不做的事）

- ❌ 不发超线券：面额 > 单均毛利 × 30% 的方案一律否决并给顶格替代
- ❌ 不编造核销率：无历史数据时按 28% 起测并显式标注假设
- ❌ 不做无差别大额券：必须写明发放名单圈选口径，禁止全量发召回券
- ❌ 不承诺效果：只给测算区间，不出现「保证唤醒率 X%」
- ❌ 不替代店主决策：预算上限与亏损容忍度由店主确认

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "shop": "青禾轻食（写字楼店）",
  "客单价": 42,
  "毛利率": 0.58,
  "渠道费率": 0.0,
  "核销率": 0.33,
  "月发放量": 1500
}
```

**输出**（脚本实跑）：

| 方案 | 面额 | 门槛 | 有效期 | 面额占毛利 | 券后毛利率 | 总券成本 | ROI |
|---|---|---|---|---|---|---|---|
| 引流券（轻触达） | 3 元 | 满 46 | 14 天 | 12% | 55% | 1,485 元 | 7.12 |
| 复购券（会员日常） | 5 元 | 满 55 | 10 天 | 21% | 52% | 2,475 元 | 3.87 |
| 召回券（沉睡强召回） | 7 元 | 满 63 | 7 天 | 29% | 50% | 3,465 元 | 2.48 |

安全面额上限 7.3 元（单均毛利 24.4 元 × 30%），门槛 = 客单 42 × 1.3 ≈ 满 55 减。三档全部在安全线内，ROI ≥ 1.5，判定**可执行**。
