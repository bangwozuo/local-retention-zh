# 封号合规风控

在触达动作执行**之前**，把会导致限权、封禁、客户投诉的操作挑出来，并给出**合规替代方案**。

不做的事：不产出营销内容、不协助规避平台检测、不推荐任何非官方自动化工具。只做放行/拦截判断。

## 元信息

| 字段 | 值 |

| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

按四个维度做分级风控审查，输出**可执行的放行判定**：

1. **频次类**——个人号日加 ≤ 20-30 人且通过率 < 50% 停手；群发 ≤ 1 条/天/客户、营销群发每周 ≤ 2 次；新号养号 7-14 天（只聊天不加人）；朋友圈营销 ≤ 3 条/天
2. **内容类**——诱导分享（转发/集赞才能领）、资金敏感词（转账/返现/加V）、虚假紧迫、跨号导流小号矩阵
3. **行为类**——单次群发删除率 > 5% 为降权信号；投诉累计 2-3 次封禁；通过率 < 50% 说明来源场景不合格
4. **工具类**——协议 bot、群控、模拟器多开、自动加人软件**绝对拦截，无替代方案**；唯一安全路径是企微官方 API + 官方频控内的人工操作

判定分三级：🔴 拦截（必须改）/ 🟡 缓行（降频或改写）/ 🔵 提示（有更优做法）。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `action` | string | ✅ | 待审动作描述：加人计划 / 群发计划 / 活动方案 / 朋友圈排期 / 拟用工具 |
| `plan` | string | ✅ | 具体计划内容：频次、话术、工具名、账号情况（新号/老号/有无限权记录） |
| `account_status` | string | ⬜ | 账号状态；有降权记录的账号从严处理 |

## 输出规格

- `summary`：受审动作 / 频次核算 / 拦截与缓行计数 / 整体判定（放行 / 修改后放行 / 拦截）
- `violations`：违规清单（级别 / 原计划 / 命中规则 / 风险后果 / 合规替代）
- `account_advice`：账号健康建议（养号/降频/分流）

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供待审动作 + 具体计划 + 账号状态
4. 得到分级违规清单与合规替代方案

### 方式二：人工复核关键点（本技能无脚本）

风控判断依赖语境（如「通过率下降的原因」），由模型按 prompt.txt 判断；执行前由店长对照本表二次确认：

| 硬性自检 | 通过标准 |
|---|---|
| 每个客户每天收到几条？ | ≤ 1 条（营销类每周 ≤ 2） |
| 有没有「转发/集赞才能领」？ | 无 |
| 有没有用自动化工具？ | 无（只用企微官方功能） |
| 加人通过率今天多少？ | ≥ 50%，否则停手 |

## 边界（不做的事）

- ❌ 不推荐协议 bot、群控、模拟器、自动加人软件——一律拦截
- ❌ 不提供「换设备、养小号池、错峰批量加人」等规避检测方案——属违规协助
- ❌ 不设任何形式的「转发才能领」门槛——诱导分享无安全变体
- ❌ 不编造平台规则细节——不确定处标注「以官方为准」
- ❌ 风控判断不能替代平台官方审核；客户个人信息操作须遵守《个人信息保护法》

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "action": "沉睡客户唤醒群发计划",
  "plan": "3 个注册 5 天的个人号，用群控工具按名单每天各加 60 个客户，通过后立即群发「转发本条到朋友圈，截图领取 30 元券」，每日 2 条。部分话术含「加V返现」。",
  "account_status": "新号（注册 5 天），无历史营销记录"
}
```

**输出**（按 prompt.txt 规则审查）：

| # | 级别 | 原计划 | 命中规则 | 风险后果 | 合规替代 |
|---|---|---|---|---|---|
| 1 | 🔴 | 群控工具批量加人 | 工具类·协议/群控 | 设备指纹识别，封号不可申诉 | 停用工具，人工用企微按名单添加 |
| 2 | 🔴 | 新号注册 5 天即营销 | 频次类·新号养号 7-14 天 | 高概率封号 | 养号至满 14 天，期间正常聊天+朋友圈日常 |
| 3 | 🔴 | 日加 60 人/号 | 频次类·日加 ≤ 20-30 | 加人限权 24h-7 天 | 日加 ≤ 15 人/号，通过率 < 50% 停手 |
| 4 | 🔴 | 转发朋友圈才能领券 | 内容类·诱导分享 | 内容处理+账号降权 | 进群/1v1 直接领，分享不设门槛 |
| 5 | 🔴 | 「加V返现」话术 | 内容类·资金敏感词 | 支付风控+封号 | 「到店出示本消息享受会员价」 |
| 6 | 🟡 | 日群发 2 条/客户 | 频次类·群发 ≤ 1 条/天 | 投诉累积→封禁 | 每客户每日 ≤ 1 条，营销每周 ≤ 2 |

整体判定：**拦截**（红线 5 项）。整改后：企微官方通道 + 每客户每日 1 条 + 无门槛领券，重新送审。
