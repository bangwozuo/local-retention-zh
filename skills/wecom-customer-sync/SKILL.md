# 企微客户对接

把企微里的客户/群/标签/事件数据按 SOP 安全取出、送进分层与触达技能，并把结果写回。
**只读优先**：不持有 API Key、不替用户授权，写操作全部经过人工确认点。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_03_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 复购管家 |
| 能力族 | 调度连接型 · 数据链路（T4） |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★★（本仓全部工作流的数据源） |
| 资产形态 | 纯提示词（SOP + 字段映射，无运行时依赖） |

## 能力描述

1. **双通道授权**：通道 A = 企微官方 API 自建应用（只读权限起步，写权限单独申请确认）；通道 B = 管理后台人工导出（T+1）；A 失败即降级 B，禁止用非官方工具补位
2. **三条时间轴**：每日增量（22:00/次日 9:00，新增客户 + 删除拉黑事件 + 打标清单）、每周全量（周一 10:00，全量快照 diff + 群清单 + 沉睡 30/60/90 分桶预计算）、触达回写（活动 T+1，券码核销以收银系统为准）
3. **每步失败处理与人工确认点**：接口重试 1 次转通道 B；客户数波动 > 10% 人工核对；打标清单店主过目后执行；批量写 > 100 人分批确认
4. **数据合规红线**：最小必要（不同步聊天内容）、手机号脱敏（只留后 4 位）、删除权 3 个工作日内响应、凭证不进对话与产物

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `system` | string | ✅ | 目标系统：企业微信（其他系统走各自连接器） |
| `task` | string | ✅ | 同步任务：每日增量 / 每周全量 / 触达回写 / 单次导出 |
| `channel` | string | ⬜ | 指定通道 A 或 B；不填则按「A 优先、B 降级」自动选择 |
| `time_window` | string | ⬜ | 数据时间窗，如「2026-09-01 至 09-30」 |

## 输出规格

- `sync_record`：同步执行单（通道 / 数据新鲜度 / 拉取范围 / 记录数 / 字段缺口）
- `write_list`：打标/回写执行清单（客户脱敏标识 / 动作 / 依据），**须人工确认后才执行**
- `data_package`：交给下游的 `客户事件流.json` 字段映射（customer_id / added_at / last_interact_at / dormant_days / tags / group_ids）

## 使用步骤

### 方式一：纯提示词（字段映射与 SOP 咨询）

1. 打开你的 AI 工具，把 `prompt.txt` **全部内容**粘贴为系统提示词
2. 说明同步任务与现状（有无 API 条件、客户量级）
3. 得到通道选择建议、字段映射与执行清单模板

### 方式二：按 SOP 实际执行（推荐节奏）

1. **首次**：店主在企微管理后台创建自建应用（只读）→ 填凭证到平台连接器（不进对话）
2. **每日 22:00**：按「每日增量」表执行 4 步，产出客户事件流
3. **每周一 10:00**：按「每周全量」表执行，产出沉睡分桶快照
4. **活动 T+1**：按「触达回写」表回写，名单先经店长核对
5. 下游消费：`dormant-customer-wake-flow` / `group-welcome-tag-flow` / `instore-redemption-guide-flow`

## 边界（不做的事）

- ❌ 不使用爬虫、协议机器人、外挂多开等非官方工具连接企微/微信
- ❌ corpid / secret / token 不出现在对话、脚本、产物文件中——出现即为事故
- ❌ 不导出聊天内容，只同步元数据（时间/事件）
- ❌ 不做静默批量写：打标/改备注/群发必须有人工确认点
- ❌ 不补零造假：接口缺失就标注缺失，不用假数据做分层

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "system": "企业微信",
  "task": "每周全量同步：全量客户快照 + 群清单 + 沉睡 30/60/90 分桶",
  "channel": "B（未开通 API，管理后台人工导出）",
  "time_window": "2026-09-22 至 2026-09-29"
}
```

**输出**（按 SOP 生成，节选）：

| 项 | 内容 |
|---|---|
| 通道 | B（人工导出，T+1 新鲜度） |
| 拉取范围 | 全量客户 / 群清单 / 最近互动时间 |
| 记录数 | 客户 1,842 条 / 群 6 个 |
| 字段缺口 | 「最近互动时间」导出缺失 214 条 → 标注缺失，按「添加时间」兜底并显式标记 |
| 沉睡分桶 | 30-59 天 312 人 / 60-89 天 189 人 / ≥ 90 天 96 人 |

打标执行清单（节选，须店长确认后执行）：本周新增 38 人中 26 人打「来源-到店扫码」、9 人打「来源-外卖包裹卡」、3 人待确认。
