# 朋友圈文案生成

把今天的门店素材写成**像店主本人发的**朋友圈：口语、有细节、不喊口号，让街坊客户记得这家店。

不做的事：不编素材、不写广告腔、不做假紧迫、不替老板发布（人工确认后发）。

## 能力描述

1. **内容配比规划**：生活/幕后 50-60% + 产品/促销 30% + 互动/人设 10-20%；营销 ≤ 3 条/天、总量 ≤ 5 条、21:30 禁屏、同一产品两天不重复
2. **发布时段对位**：7:30-9:00 早餐档 / 11:00-11:30 午市前 / 17:00-18:00 晚市前 / 20:30-21:00 情感档——按客户到店决策点发
3. **五关写作规则**：≤ 140 字防折叠、首句 10 字钩子、1 个真实细节（数字/名字/时间）、配图 1/3/4/6 张、结尾 1 个轻动作（提问/接龙/到店暗号自带归因）
4. **五种骨架模板**：新品上市 / 天气借势 / 幕后信任 / 限时 specials / 客户返图，每次产出 3 条不同骨架候选
5. **三条硬性自查**：极限词扫描（《广告法》）、诱导分享检查、AI 标识与人工确认

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `brief` | string | ✅ | 今天写什么：新品 / 天气 / 幕后 / 促销 / 返图 |
| `materials` | string | ✅ | 真实素材：进货时间、数量、客人反应、天气、库存等细节（缺细节时 AI 会列清单索要，不编） |
| `shop_persona` | string | ⬜ | 店主人设口吻（如：话痨暖男火锅店老板 / 高冷手作店主） |
| `today_limit` | number | ⬜ | 今天已发条数，用于频控核算 |

## 输出规格

- `candidates`：3 条候选（骨架类型 / 发布时段 / 配图建议 / 文案全文 ≤ 140 字 / 评论区补位）
- `self_check`：字数 / 极限词 / 诱导分享 / 细节真实性 四项自查
- `recommendation`：推荐 1 条及理由

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 给 brief + 真实素材（越具体越好）
4. 得到 3 条候选 + 自查结果，店主挑 1 条人工确认后发

### 方式二：每日流程串联（推荐）

1. 每天早上由 `daily-moments-copy-flow`（T3 工作流）自动排当天选题与时段
2. 本技能按选题产出 3 条候选
3. 产出过 `account-ban-risk-control` 风控自查（极限词/诱导分享/频控）
4. 店主确认后按建议时段手动发布

## 边界（不做的事）

- ❌ 不编素材——细节缺失列清单索要，不虚构「今早现摘」类细节
- ❌ 不用广告腔——「欢迎品尝」「匠心之作」一律不出现
- ❌ 不做假紧迫——库存充足不写限量，促销理由必须真实
- ❌ 不超频——单日建议 ≤ 5 条，营销 > 3 条主动提醒砍量
- ❌ 不写竞品贬损、不推荐网图/盗图；客户返图与昵称须本人同意

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "brief": "新品上市：今早现熬的酸梅汤，搭配烧烤档周末预热",
  "materials": "凌晨 4 点用乌梅+山楂+桂花熬了 6 小时，出 50 升；昨天试喝的客人（穿工装的小哥）连喝两杯说像小时候的味道；明天周六烧烤档出摊",
  "shop_persona": "话痨暖男烧烤店老板",
  "today_limit": 1
}
```

**输出**（按 prompt.txt 规则生成，候选 1 节选）：

> 凌晨四点，整条街就我家烟囱在冒烟——乌梅山楂桂花，咕嘟了整整 6 个钟头。
> 昨天试喝的工装小哥连干两杯，说了句「像小时候的味道」，老板听完当场决定多熬一倍。
> 今天 50 升，卖完等明天。你们说，酸梅汤配烤串，是不是天造地设？
>
> 配图：3 张（熬制锅特写 / 成品杯 / 灶台全景）｜发布时段：11:00-11:30｜评论区补位：「明天烧烤档出摊，酸梅汤免费续杯一次，暗号『小时候』」

自查：字数 138 ✅｜极限词无 ✅｜诱导分享无 ✅｜细节全部来自素材 ✅

> 完整 3 条候选与推荐理由见 docs/04-examples.md。
